# Navegación

Los nodos representan lugares o puntos del recorrido y las aristas representan conexiones.
Cada arista posee distancia y una bandera de accesibilidad.

Dijkstra busca el camino de menor costo sin heurística.
A* añade una heurística basada en X/Y para orientar la búsqueda.

La demo conecta Entrada principal → Ascensor → Ascensor P2 → Pasillo P2 → Sala 205.
También existe una escalera marcada como no accesible para probar el filtro.
